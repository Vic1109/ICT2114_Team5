Context update behavior
Keeps every source in the active corpus and adds only new archive records and CTI documents.
Existing sources will not be part of the newly active corpus unless selected again.
The first successful build creates the initial context; later builds extend it by default.
Advanced notes

Replacement is a destructive corpus operation and requires confirmation. Status refresh (no sources selected) does not mutate the corpus. Duplicate uploads are skipped after a hash check against the database.

      "agent": {
